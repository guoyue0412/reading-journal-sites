# 郭跃的个人主页

记录研究项目、论文阅读、秋招、实习与个人随笔。

所有内容都是 `content/` 目录下的 Markdown 文件，点开即可阅读。

## 目录

- **论文阅读** → [`content/papers/`](./content/papers/)
- **秋招记录** → [`content/jobs/`](./content/jobs/)
- **实习日记** → [`content/internship/`](./content/internship/)
- **个人感悟** → [`content/reflections/`](./content/reflections/)

## 如何发布

1. 在对应目录新建 `.md` 文件，参考同目录已有文章的 frontmatter 格式
2. 提交并 push 到 `main`
3. 在 GitHub 上直接阅读，或开启 Pages 获得更好排版
