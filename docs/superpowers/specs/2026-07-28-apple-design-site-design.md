# 全站 Apple Design 升级设计

## 目标

在不改变博客内容模型、路由或阅读优先级的前提下，将首页、索引、文章页和结构化编辑器升级为具有 Apple 式清晰层级、即时反馈与跨设备适配的界面。

## 视觉原则

- 保留现有暖纸色、宋体正文与编辑性阅读气质；不改造成高饱和度的通用应用面板。
- 系统无衬线字体用于导航、控件、状态与元数据；衬线字体继续承担长文阅读。
- 使用三层材质：纸张背景、轻量半透明工具层、实体内容卡片。不会在两个玻璃层之间叠放文本。
- 以留白、对比和字号建立层级，圆角与阴影只用于交互层和临时浮层。

## 阅读端

- 顶部导航在滚动时以轻磨砂材质浮于内容之上，保留明确的当前位置与 44px 触控目标。
- 首页模块、索引筛选器和文章关联内容采用一致的按压反馈、键盘焦点和短暂位移，避免无意义的大幅动画。
- 文章正文维持最大可读宽度；元数据、关联文章和筛选器使用低干扰的独立表面。

## 编辑器

- 工具栏固定在编辑工作区顶部，展示保存状态、导入导出与发布操作；发布作为唯一强调操作。
- 侧栏、编辑区与预览区通过背景、边界和间距区分；编辑模块作为可操作实体，结构化模块类型可被快速辨识。
- 错误、保存、冲突状态使用语义颜色和清晰文案；不依赖动画传达状态。
- 手机端保留编辑/预览切换，工具栏可横向滚动，按钮保持适合触控的最小尺寸。

## 动效与无障碍

- 交互反馈只使用 transform、opacity、background-color 和 box-shadow；默认 160–240ms 的缓和过渡，按下即时缩放至 0.98。
- 不新增会阻塞输入或不可中断的装饰性动画。
- `prefers-reduced-motion` 下关闭位移与缩放，仅保留短暂颜色/透明度变化。
- `prefers-reduced-transparency` 下工具层转为实体背景；`prefers-contrast: more` 下增强边界和文字对比。

## 验收标准

- 首页、四个内容索引、文章页与编辑器共享同一套颜色、字体、交互与焦点规则。
- 在桌面、平板和手机断点下没有横向页面溢出；编辑器的文章列表、编辑与预览仍可访问。
- 现有的写作、自动保存、Markdown 导入导出、结构化组件与发布逻辑保持不变。
- 自动化源码测试覆盖新的可访问性、响应式和编辑器材质钩子；完整构建和测试通过后再发布。
