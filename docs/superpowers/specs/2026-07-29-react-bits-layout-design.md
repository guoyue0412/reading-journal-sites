# React Bits 局部增强全站排版设计

## 目标

在不改变博客的文章数据、论文索引、LaTeX 渲染和结构化编辑能力的前提下，建立一套统一的「研究者工作台」视觉语言。互动感只服务于定位、扫描与操作反馈，不打断长文阅读与写作。

## 视觉系统

- 基底：暖白纸张与深墨文字；蓝紫是页面环境光，朱砂红只标记当前动作、阅读进度和重要状态。
- 材质：导航、工具栏与卡片采用同一层级的半透明面板、细描边和柔和投影；不叠加多层玻璃。
- 动态：背景光晕缓慢漂移，卡片在悬停时抬升 2px、显示边缘高光；按钮在按下时缩放。所有动态可由系统的减少动态效果偏好关闭。
- 字体：大标题用紧凑衬线字，界面标签用字距稍宽的无衬线字，正文保持现有舒适行距。

## 页面规则

### 首页

首屏使用低对比的「环境光 + 点阵」背景；四个内容模块、阅读动态和进度概览使用相同的浮层边界、渐变高光和悬停反馈。

### 索引

索引头部作为稳定的路标，筛选、论文矩阵、秋招漏斗和列表条目复用统一的交互面板。筛选状态以颜色、描边和文本反馈表达，而不是持续动画。

### 文章

文章标题区采用轻量的环境光，元数据为清晰的资料卡。正文、数学公式、表格、代码和相关文章区域维持纯净、固定的阅读节奏，不使用位移动画。

### 编辑器

编辑器为可编辑的工作台而非展示页：保存状态、工具栏、侧栏、模块卡和预览区共享材质规则；输入焦点、发布、模块新增等操作均有短促、可预期的反馈，不能抢焦点或延迟自动保存。

## 响应式与无障碍

- 桌面维持多列索引和三栏编辑器。
- 平板将列表压缩为双列/双栏，并保留触摸目标。
- 手机使用单列和抽屉式导航，编辑器维持编辑/预览切换。
- `prefers-reduced-motion` 下背景静止，所有位移和循环动画关闭；提高对比度和减少透明度偏好继续生效。
