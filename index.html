RoboDojo

大小脑协同框架

在研 · 分层机器人策略

让上层任务决策与下层动作预测各司其职，协同处理长程机器人操作。

大脑维护子目标与执行进度，并对小脑提出的动作候选作高层判断；小脑根据任务指令与当前可获得的观测预测短时动作。

研究重点：任务进度判断、动作候选审查与执行反馈。

大小脑协同 / 框架示意

V

大脑 VLM

结合当前与历史多视角观测，维护子目标和进度，判断动作候选。

↓ 高层判断↑ 动作候选
W

小脑 WAM / OminiEWM

以任务指令、观测历史与本体状态为条件，预测短时动作序列。

↺执行后的实测观测纳入历史，为后续判断与动作预测提供反馈。

World-Action Model

WAM

用未来表征连接视频与动作

智源 BAAI · 框架设计与实现

以视频教师学习动态信息，由 PolicyDiT 学习未来相关表征，再交给 ActionExpert 解码动作序列。

将多源动作统一到头部相机坐标系下、相对固定当前帧的末端位姿变化，并开展多视角建模。

Dream4ACT

跨本体视觉动作接口

ICLR 2027 · 已投稿

A Shared Visual Action Interface for Multi-Embodiment Video-Action Modeling

将异构机器人的关节配置表示为多视角动作视频，复用视频骨干联合建模观测与动作，再通过几何匹配恢复可执行关节轨迹。

方法与评测结果

基于 URDF 构建四视角动作视频，通过 training-free 多视角几何匹配恢复动作。动作视图的构建与恢复无需真实相机外参对齐或本体专属动作解码头。

RoboTwin2.0 全部 50 项任务，Clean / Randomized 两种设置的平均成功率为 88.98%。另一组跨本体联合训练实验以固定权重支持四种真机平台，放置与擦拭两项共同任务的平台平均成功率为 85%–90%。

指标为论文报告；全 50 项任务评测与跨本体实验使用不同 checkpoint。

WEAVE-0.5

多流具身世界模型

ICLR 2027 · 已投稿

Weaving Multi-stream Observations into Embodied World Models

统一可变视角、混合分辨率与多模态观测，以单一模型支持未来预测、跨视角补全和模态互转。

参与模型训练与数据消融，搭建评测平台，开展 bad case 分析与数据回流。

方法与评测结果

通过原生分辨率独立编码、共享虚拟画布与跨流注意力进行多流建模。工程工作包括 YouTube 视频管线和 Sim–Real 成对数据生产链路。

MV-261 上联合生成深度流，主视角 PSNR 从 15.74 提升至 17.87 dB（+2.13 dB）。论文报告 RBench 第一、TriWorldBench 第二。

榜单名次对应论文中的评测快照。Sim–Real 演示展示数据生产链路，不是 WEAVE 模型生成结果。

Colugo

多尺度潜在世界模型引导 VLA

协作研究 · 2026.04.26–06.04

从 VLM 隐藏状态中预测慢、快两种尺度的潜在未来，以未来表征调制动作生成。

方法与验证设置

以 learnable slow / fast queries 从 VLM hidden states 预测 latent futures，通过 dual cross-attention 与 MLP fusion 调制 flow-based Action DiT。

在 LIBERO-Long、CALVIN ABC→D 和 AgileX Nero + RealSense D455 上完成 no future / slow only / fast only / slow+fast 消融与真机验证，推理时移除 reconstruction decoder。
