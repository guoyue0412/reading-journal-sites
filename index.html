Dream4ACT

跨本体视觉动作接口

ICLR 2027 · 已投稿

A Shared Visual Action Interface for Multi-Embodiment Video-Action Modeling

基于 URDF 将异构关节配置表示为四视角动作视频，复用视频骨干联合建模观测与动作。通过 training-free 多视角几何匹配恢复可执行关节轨迹，动作视图的构建与恢复无需真实相机外参对齐或本体专属动作解码头。

RoboTwin2.0 全部 50 项任务，Clean / Randomized 两种设置的平均成功率为 88.98%。另一组跨本体联合训练实验以固定权重支持四种真机平台，放置与擦拭两项共同任务的平台平均成功率为 85%–90%。

指标为论文报告；全 50 项任务评测与跨本体实验使用不同 checkpoint。两篇论文均为已投稿状态。

WEAVE-0.5

多流具身世界模型

ICLR 2027 · 已投稿

Weaving Multi-stream Observations into Embodied World Models

通过原生分辨率独立编码、共享虚拟画布与跨流注意力，统一可变视角、混合分辨率及多模态观测。单一模型支持未来预测、跨视角补全和模态互转。

参与模型训练与数据消融，搭建评测平台，开展 bad case 分析与数据回流；建设 YouTube 视频管线和 Sim–Real 成对数据生产链路。

MV-261 上联合生成深度流，主视角 PSNR 从 15.74 提升至 17.87 dB（+2.13 dB）。论文报告 RBench 第一、TriWorldBench 第二。

榜单名次对应论文中的评测快照。Sim–Real 演示展示数据生产链路，不是 WEAVE 模型生成结果。

WAM · 未来表征与动作预测

智源 BAAI · 框架设计与实现

以 Cosmos-Predict2.5-2B 为视频教师，通过 PolicyDiT 学习未来相关表征，由 ActionExpert 解码动作序列。教师仅由 L_video 更新；学生的 L_align 与 L_action 均不更新教师。

统一多源动作表示为头部相机坐标系下、相对固定当前帧 t₀ 的 EE pose delta，结合多流 RoPE 与视角特征向量进行多视角建模。
